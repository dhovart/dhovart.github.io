  • cargo-local-registry desde 2021, Rust

    Um subcomando do Cargo que monta um registro local a partir de um lockfile, para compilar Rust em máquinas sem acesso à internet. Criado por Alex Crichton em 2016, passado para mim em 2021. Mantenho-o funcionando através das mudanças na API interna do Cargo, adicionei um comando add para crates individuais e movi a integração contínua e os binários pré-compilados para o GitHub Actions. Mais de 300.000 downloads no crates.io.
